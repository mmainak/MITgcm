# Sediment Transport Test Case

This experiment tests the sediment transport package with:
- Multiple sediment classes
- Temperature-dependent settling
- Erosion and deposition
- Bed layer evolution

## Configuration
- 2 sediment classes
- 3 bed layers
- Temperature and salinity effects on settling
- Diagnostic outputs

## Running the Test
1. cd build
2. ../build.bash
3. cd ../run
4. ln -s ../input/* .
5. ../build/mitgcmuv
